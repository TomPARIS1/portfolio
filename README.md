# Portfolio

Mon portfolio personnel, développé avec TypeScript, Next.js et Tailwind CSS, pour présenter mes compétences, projets et services en développement web freelance.

---

## 🚀 Démo

👉 [Voir en ligne](https://tomparis.vercel.app)

---

## 🎯 Objectif

Ce projet a pour but de créer une vitrine professionnelle simple, responsive et moderne afin de présenter mon profil, mes technologies favorites et mes projets réalisés. Il me permet de montrer concrètement mes compétences et d’attirer mes premiers clients freelance.

---

## ⚙️ Tech Stack

- **Langage :** TypeScript  
- **Framework :** Next.js  
- **CSS :** Tailwind CSS  
- **Déploiement :** Vercel

## 🔧 Fonctionnalités principales

- Site responsive et accessible sur mobile, tablette et desktop  
- Présentation claire de mes compétences et projets  
- Formulaire de contact fonctionnel pour faciliter la prise de contact  
- Téléchargement du CV en un clic  
- Navigation fluide et intuitive

## 🚀 Installation (pour tester en local)

```bash
# Cloner le repo
git clone https://github.com/tomparis/portfolio.git

# Se déplacer dans le dossier
cd portfolio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
